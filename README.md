# 🎮 Bajte Brothers - Cyberpunk Rescue 3.0

Cyberpunk top-down shooter igra napravljena sa React, TypeScript, Vite i Tailwind CSS.

## 🕹️ Kontrole

| Akcija | Tastatura | Miš |
|--------|-----------|-----|
| Kretanje | WASD / Strelice | - |
| Nišan + Pucanje | - | Pomjeraj + Klik |
| EMP Shockwave | E | - |
| Pauza | ESC | - |
